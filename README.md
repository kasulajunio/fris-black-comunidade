# fris-black-comunidade

Comunidade pública do **Brasil em Pauta**, da **Fris Black Estúdio**, para debates, sugestões e avaliações. Não publique dados pessoais.

- Leia o [Guia de participação](GUIA_DE_PARTICIPACAO.md) antes de criar uma discussão.
- Use o [modelo de sugestão e correção](MODELO_DE_SUGESTAO_E_CORRECAO.md) para enviar contribuições claras e verificáveis.
